Projects

AssenSAR: Assessment of Sea Surface Signatures for Naval Platforms using SAR Imagery Assessment of Sea Surface Signatures for Naval Platforms using SAR Imagery (AssenSAR) is an EPSRC funded project led by Prof. Alin Achim. This project is concerned with the development and validation of new sea surface models but also with the design of very advanced methods for enhancing SAR image quality and for subsequent information extraction.
Automated Alert System for Volcanic Unrest This project develops an effective and efficient automated global volcano alert system using Interferometric Synthetic Aperture Radar (InSAR) data, which can detect surface deformation, having a strong statistical link to eruption.
